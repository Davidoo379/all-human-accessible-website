# Accessible Website
Ontwerp en maak voor het project Pediaconnect, een website toegankelijk volgens WCAG richtlijnen.
Voor de een groep Kinderartsen die in opdracht zijn van de KvK.

## Beschrijving
### Rol: wie zijn wij?
Als frontenders maken wij websites die responsive <em id="responsive">(toegankelijk op verschillende schermen)</em>, accessible <em id="accessible">(voor mensen met beperkingen)</em>, statisch (zonder echte opgeslagen data) zijn.

### Opdracht: wat wilt de school van ons?
Wij hebben van school de opdracht gekregen om minimaal aan deze eisen te voldoen: 1 content pagina (een hoofdpagina waar links in staan naar andere paginas), 1 detail pagina (een individuele informatie pagina).

### Doel: wat gaan wij bijdragen aan het project?
Obstakels vinden en oplossingen maken bij het omzetten van het ontwerp naar een statische website die <a href="#responsive">responsive</a> en <a href="#accessible">accessible</a> is.

## Resultaat
Wat leveren we op voor de volgende mensen die aan dit project werken?
Een collectie van repositories (online werkomgeving waar alle code te vinden is) met gedocumenteerde oplossingen en veranderingen aan het design. Ook de gebruikte technieken 

### Gebruikte Technieken
HTML, CSS, JS zijn de talen die ik heb gebruikt. Alles talen in zijn eigen file maar niet meerdere ervan, zodat het simpel blijft. 
### Obstakels met responsiveles
Er is een boven bar en onder bar die bij de desktop verzie linkt komen te staan. ik heb css gebruikt om de hele pagina een grid te maken en ze daar neer te zetten. Het breakpoint zit bij 900px.
### Obstakels met accesibility
Met lighthouse, A11Y checklist en de WCAG rightlijnen heb ik gechecked of deze pagina toegankelijk is.
Er waren een paar dingen die van het design aangepast moesten worden.
